# Jengo.AI — Bunifu Suite Ecosystem

> **JENGA (v.)** — Swahili: *to build, to construct*

A high-contrast construction-grade ecosystem for every **Bunifu Suite** application — engineered to feel like heavy infrastructure for creators, developers, and communities.

---

## 🏗️ Design Language (Jengo DS v1.0)

The application implements the **Jengo AI Design Language v1.0**:

- **Palette Ratio:** Jengo Black (`#0A0A0A` - 60%), Paper White (`#FAF9F5` - 32%), Bunifu Yellow (`#FFD100` - 8%), Yellow Tint (`#FFF6C9`), Site Gray (`#6B6A63`), Hairline (`#DCDACF`).
- **Signature Hazard Stripe:** Repeating 45° diagonal gradient marking building status, active pipelines, and section boundaries.
- **Typography:** Space Grotesk (Display / Headlines), Inter (Body copy), JetBrains Mono (Utility / Tags / Metadata).
- **Hard Edges & Signal Motifs:** 2px solid black borders, 6–8px corner radii, flat line iconography, monospace telemetry readouts.

## ⚡ Key Capabilities & Features

- **Dual Perspective Modes:**
  - *Editorial Monograph:* High-craftsmanship comprehensive architectural review with deep descriptions and capability checklists.
  - *Blueprint Grid:* High-density interactive matrix with coordinate tags and quick launch actions.
- **Dynamic Search & Filtering:** Instant keyword query across tool names, capability descriptions, taxonomy tags, and audience targets.
- **Architectural Spec Drawer (Modal):** Inspect deep system specifications, copy direct links, and evaluate pipeline stages.
- **Creator Journey Pipeline:** 5 synchronized lifecycle stages — *Build*, *Ship*, *Get Seen*, *Get Paid*, *Automate*.

## 💻 Tech Stack

- **Frontend:** React 19 + TypeScript
- **Bundler:** Vite 6
- **Styling:** Tailwind CSS V4 (`@theme` definitions + custom gradients)
- **Icons:** Lucide React
- **Fonts:** Space Grotesk, Inter, JetBrains Mono

## 🚀 Development Setup

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```
